## How to Run Locally

You can edit, customize, or run this portfolio locally using your favorite code editor.

### Prerequisites

- Node.js & npm (recommended to install via [nvm](https://github.com/nvm-sh/nvm#installing-and-updating))

### Steps

```sh
# 1. Clone the repository
git clone https://github.com/CoderRdm/ridamgoyal-folio.git

# 2. Navigate to the project directory
cd ridamgoyal-folio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
